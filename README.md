# Factor Ball｜因數球球

這是一款以「因數分解」為核心的互動式球體整理遊戲。玩家會看到一群彩色球體，透過分組、消除和整理，將整體數值逐步拆解成更小的因數，最後確認是否為質數。

遊戲檔案： [factor-ball.html](./factor-ball.html)

## 遊戲目標

每一局都會出現一個固定數量的球體，目標不是單純消除，而是：

- 將球體整理成多個「等量分組」
- 選擇一個可行的分組方案後按下「完成分組」
- 消除多餘的分組，保留其中一組作為新的基準
- 持續重複，直到剩餘球數可被判定為質數
- 將最後的質數球投入「質數垃圾桶」完成關卡

簡單來說，這是一個把大數拆成因數、再拆成質因數的視覺化因數分解遊戲。

## 遊戲規則

### 1. 分組條件

- 只要存在至少兩個「球數相同」的群組，就能完成分組
- 例如：12 顆球可分成 3 組 × 4 顆，或 2 組 × 6 顆
- 完成分組後，系統會保留其中一組，消除其餘組別
- 過程中，遊戲會更新因數樹與公式顯示，讓玩家能看見數字如何拆解

### 2. 兩種模式

#### 自由磁吸模式

- 可直接拖曳球體
- 也可用滑鼠框選多顆球
- 球體靠近時會自動形成「磁吸群組」
- 當群組大小一致時，可按下「完成分組」

#### 隊列模式

- 讓球體排成等寬的列
- 每一列都視為一個分組
- 調整「列數」滑桿，讓每列的球數相同
- 當列數正確時，即可按下「完成分組」

### 3. 質數判定

- 當平台上剩下的球數是質數時，按下「質數垃圾桶」即可完成關卡
- 若不是質數，系統會扣減分數並提示玩家繼續分解
- 成功找到質數後，遊戲會揭開質數卡牌，並顯示慶祝動畫

## 操作方式

### 基本操作

- 拖曳球體：將球體移到指定位置
- 框選球體：拖曳選取框選區域中的球
- 完成分組：在符合條件後點選右側按鈕
- 質數垃圾桶：當剩餘球數為質數時使用

### 介面說明

- 左側大畫布：遊戲主場景
- 右側面板：顯示分組狀態、分數、回合、模式切換與控制按鈕
- 上方公式區：顯示目前的數值分解進度
- 質數卡牌區：記錄已解鎖的質數
- 狀態欄：顯示提示、規則、錯誤訊息與成功回饋

## 玩法流程

1. 開啟 [factor-ball.html](./factor-ball.html)
2. 觀看目前球數與提示
3. 將球分成等量群組（自由模式或隊列模式）
4. 點擊「完成分組」
5. 重複直到剩餘球數能被視為質數
6. 點擊「質數垃圾桶」完成關卡
7. 每次成功都會累積分數，並記錄因數樹演化

## 得分機制

- 成功完成分組：會增加分數
- 消除更多球體：通常能得到更多獎勵
- 成功送入質數垃圾桶：加分更多
- 若判定錯誤（例如剩餘球數不是質數）會扣分

## 技術說明

這個遊戲是一個單一 HTML 檔案，沒有額外依賴或建置流程，直接在瀏覽器中開啟即可執行。

如果你想在本機以本地伺服器方式開啟，可以在專案資料夾執行：

```bash
python -m http.server 8000
```

之後開啟瀏覽器訪問：

```text
http://localhost:8000/factor-ball.html
```

## 建議玩法策略

- 先觀察目前球數的可分組方式
- 優先找出「整體數值最容易拆成幾個相同群組」的組合
- 若球數很大，先拆成小因數，再逐步逼近質數
- 在隊列模式中，調整列數通常比手動拖曓更直覺

## 總結

Factor Ball 是一款將「因數分解」與「球體整理」結合的益智遊戲。它不只考驗視覺操作，也要求玩家透過數學思維找出最佳分組方式，最終將數字拆解成質因數。
